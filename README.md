# PULSE Reaction Arena

Android app wrapping the PULSE reaction game (HTML5/Canvas/JS) in a React Native WebView.

- **Package:** com.jakesadavidson.pulsereaction
- **Build:** EAS Build → .aab (Android App Bundle)
- **Game:** Single-file HTML5 canvas game with Web Audio synthesis

Built with Expo SDK 51 + react-native-webview.
